# Zone des spécimens

Mini web-app statique inspirée de l'interface fournie.

## Utilisation

Aucun serveur nécessaire.

Ouvrir simplement `index.html` dans un navigateur.

## Fonctionnalités

- IDs 005 à 010
- progression par tâche
- tâches :
  - Extraire les données du spécimen
  - Tuer le spécimen
  - Capturer le spécimen
- renommage des spécimens
- sauvegarde automatique dans `localStorage`
- responsive PC / mobile
- aucune dépendance JavaScript

## Personnalisation

Les données initiales sont dans `script.js`, dans `DEFAULT_SPECIMENS`.

Pour ajouter ou modifier des spécimens, modifier ce tableau.
